Moneymind — Quick Start

From the downloaded zip to a running app in ~20 minutes

This is the fast path. The full reference — Firebase, secrets, Remote Config, monetization, release — is in the included documentation.

Prerequisites

  • Flutter 3.x (Dart ≥ 3.11)
  • A Firebase project on the Blaze plan (Functions need it)
  • Node 22 + pnpm (for the Functions workspace)
  • Xcode (iOS simulator) and/or Android Studio (emulator)
  • The Firebase CLI (npm i -g firebase-tools) + FlutterFire CLI (dart pub global activate flutterfire_cli)

Steps

  1. Install dependencies Extract the zip, then: 
    pnpm install            # repo root — Functions workspace
cd apps/mobile && flutter pub get
  2. Wire your Firebase project From apps/mobile: 
    flutterfire configure
    Generates lib/firebase_options.dart and drops google-services.json / GoogleService-Info.plist. In the Firebase console, enable Authentication, Firestore, Storage, and Remote Config.
  3. Deploy the backend Set the five Function secrets — OPENAI_API_KEY, GEMINI_API_KEY, EXCHANGERATE_API_KEY, REVENUECAT_WEBHOOK_SECRET, REVENUECAT_API_KEY — then: 
    firebase deploy --only firestore:rules,firestore:indexes,storage,functions
  4. Codegen (only if you change models) 
    dart run build_runner build --delete-conflicting-outputs
  5. Run the app 
    flutter run
    Sign up with email + password; the setup flow seeds your first wallet.
  6. (Optional) Light up AI + monetization + social sign-in Set the Remote Config keys + secrets and the social providers (full reference in the included documentation). The app runs fine without them — AI entry points degrade gracefully, the paywall shows an unconfigured state, and ads stay hidden.
The app won't build until step 2. The Android google-services Gradle plugin needs google-services.json, and main.dart imports firebase_options.dart — both are gitignored and produced by flutterfire configure.

Build commands

# from apps/mobile
flutter build appbundle --release   # Android
flutter build ipa --release         # iOS

# tests
flutter test                        # client
pnpm -F functions test              # server

Troubleshooting

SymptomFix
Paywall says "not configured"revenuecat_api_key_* not published in Remote Config (or initRemoteConfig() couldn't fetch)
Purchase succeeds but stays FreeRevenueCat entitlement isn't named exactly premium, or no product is attached
"Couldn't run the detector" (Subscriptions)Deploy Functions + firestore:indexes (the recurringRules composite index ships in firestore.indexes.json)
AI action returns resource-exhaustedMonthly free_tier_ai_quota reached for a free user (premium bypasses)
Biometric prompt crashes / does nothingMainActivity must extend FlutterFragmentActivity (it does); iOS needs NSFaceIDUsageDescription (present)
Notifications never fireAndroid needs POST_NOTIFICATIONS + RECEIVE_BOOT_COMPLETED + the two manifest receivers
Google sign-in fails / nothing happensAndroid: app SHA-1 not registered in Firebase (re-run flutterfire configure); iOS: REVERSED_CLIENT_ID URL scheme missing. Also enable the Google provider in Firebase Auth
Apple button isn't showingBy design — iOS-only (social_sign_in_buttons.dart). On iOS, add the Xcode "Sign in with Apple" capability + enable the Apple provider
build_runner conflictsRun with --delete-conflicting-outputs
Release build fails with "keystore not found" / missing signingCopy android/key.properties.example → android/key.properties, fill in your .jks path + passwords (see index.html §15)
R8 strips a class my code reflects on (ClassNotFoundException in release)Add a -keep rule to android/app/proguard-rules.pro and rebuild
